# AC-DC Variable Power Supply

## Project Description
This project presents the design and development of an AC-DC Variable Power Supply. It includes electronic circuit simulation, PCB design, and technical documentation, combining theoretical concepts with practical electronic engineering applications.

## Project Files

### 1. Circuit Simulation
Contains the electronic circuit schematic and simulation files used to analyze and verify the power supply operation.

### 2. PCB Design
Contains the Printed Circuit Board (PCB) layout prepared for the physical implementation of the designed circuit.

### 3. Project Report
Contains the technical report documenting the project, including its design methodology, circuit operation, analysis, and results.

## Project Scope
- AC-to-DC power conversion.
- Electronic circuit design and simulation.
- PCB layout and development.
- Technical documentation and project analysis.
- Practical application of power electronics principles.
